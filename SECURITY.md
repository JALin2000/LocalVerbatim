# Security / 安全报告

## English

This is an experimental source project. Security fixes are intended for the current development branch and latest source release; older versions have no separate maintenance commitment. There is no public installer yet and no guaranteed response or fix schedule.

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/JALin2000/LocalVerbatim/security/advisories/new) when the form is available. Include the affected version or commit, impact, and minimal reproduction using synthetic data. Do not include real meeting recordings, transcripts, participant information or credentials, even in a private report.

If the private form is unavailable, do not post vulnerability details, exploit code or sensitive logs in a public issue or pull request. You may open an issue asking only for a private reporting channel, without describing the vulnerability, and wait for a private route before sharing details.

Ordinary bugs can use [public issues](https://github.com/JALin2000/LocalVerbatim/issues). Remove personal paths, titles, names and meeting content from logs/screenshots first. See [Privacy](docs/PRIVACY.md) for local data and network behavior.

## 简体中文

本项目处于实验性源码阶段。安全修复面向当前开发分支和最新源码版，不承诺单独维护旧版本。目前没有公开安装包，也不承诺固定的响应或修复时限。

疑似漏洞请优先使用 [GitHub 私密漏洞报告](https://github.com/JALin2000/LocalVerbatim/security/advisories/new)（表单可用时）。说明受影响的版本或提交号、影响及使用合成数据的最小复现方法。即使是私密报告，也不要附真实会议录音、逐字稿、与会者信息或凭证。

如果私密表单不可用，不要在公开 issue 或 pull request 中发布漏洞细节、利用代码或敏感日志。可以仅发起一个询问私密报告渠道的 issue，不描述漏洞；等私密渠道可用后再分享详情。

普通问题可使用[公开 issue](https://github.com/JALin2000/LocalVerbatim/issues)。附日志或截图前先删除个人路径、标题、姓名和会议内容。本地数据与联网行为见[隐私说明](docs/PRIVACY.md)。
