# 安装与日常使用

[English](INSTALL.md) · [README](../README.zh-CN.md)

## 安装前

需要 Apple Silicon Mac、macOS 15 或更新系统。建议 16 GB 内存；8 GB 配置和完整系统版本范围尚未验证。暂不支持 Intel Mac 和 Windows。

应用和约 4.08 GB 模型合计建议预留至少 6 GB，另留下载工作文件和录音所需空间。独立安装包内含 Python 运行时，使用时不需要开发工具或账号。

[GitHub 仓库](https://github.com/JALin2000/LocalVerbatim)提供 v0.4.7 实验性源码版，目前没有公开安装包；从源码构建请阅读[开发说明](DEVELOPMENT.zh-CN.md)。下方 DMG 安装步骤仅适用于维护者另行提供的试用包。这些包采用临时签名，尚未公证。校验和可以确认文件内容一致，但不能单独证明发布者身份。

## 安装已获得的 DMG

1. 从维护者的同一可信发行渠道获得 DMG 及其 SHA-256 校验和。
2. 在终端检查文件，将示例路径替换为实际下载路径：

   ```sh
   shasum -a 256 /path/to/LocalVerbatim-mac-arm64.dmg
   ```

3. 打开 DMG，将 **LocalVerbatim／本地逐字稿** 拖入 **Applications／应用程序**。应用文件为 `LocalVerbatim.app`；推出镜像，从应用程序中启动。
4. 若 macOS 阻止未公证试用版，请先确认来源和校验和，再参考 [Apple 官方安全打开应用说明](https://support.apple.com/en-gb/102445)。系统支持在尝试启动后，通过“系统设置 → 隐私与安全性”处理单个应用的打开请求。安装不需要关闭 Gatekeeper 或用命令移除隔离属性。“已损坏／恶意软件”提示应调查原因，不应一律视作普通权限提示。

从源码构建请阅读[开发说明](DEVELOPMENT.zh-CN.md)。开发版需要与其 runtime/engine 同目录，不能当作独立安装包直接移入 Applications。

## 首次启动与模型安装

1. 选择英文、中文或跟随系统的界面语言；它与语音识别语言相互独立。
2. 在向导中下载模型，或导入已有且版本匹配的 **Qwen3-ASR-1.7B BF16** 模型目录。
3. 下载固定 Hugging Face 版本，校验文件大小和 SHA-256。导入操作不能用其他版本或量化模型替代。
4. 下载支持暂停和继续。校验完成前保留足够磁盘空间；网络中断后可重试，已下载的部分保留。录音和识别无需登录 Hugging Face。
5. 模型就绪后可以离线录音与识别。默认模型目录为 `~/Library/Application Support/LocalScribe/Models/`，当前路径可在“设置 → 存储”查看。

## 授权并检查两路声音

按 macOS 提示允许麦克风和“屏幕与系统音频录制”，具体名称随系统版本而异。应用通过 ScreenCaptureKit 获取系统音频，不保存屏幕画面或视频。

进入**设置 → 录音**，选择输入设备，运行 **10 秒收音测试**。说一句话并让测试提示音播放，确认两路都显示“收到音频”，再分别点击回放核对内容。权限开关已打开，不一定代表设备正在提供有效音频。

会议中建议使用耳机，避免电脑外放再次进入麦克风。合盖时使用外接麦克风，内置麦克风可能被硬件断开。当前使用 Carbon 注册全局快捷键，不需要为此授予辅助功能或输入监控权限。

## 录制会议

1. 新建会议，可修改名称、术语和背景。用英文逗号、中文逗号或回车分隔术语，成功添加后会显示为独立标签。
2. 选择自动中英混合、英语或普通话，点击**开始录音**并检查两路音量。
3. 逐字稿分段更新时可同时记录笔记。关闭窗口后仍在菜单栏继续录音；退出应用会结束并保存录音。
4. 点击停止或按 **Control + Option + S**。若开启自动二次识别，会先完成待处理原稿，再开始二次识别。
5. 点击**停止二次识别**保留原稿、录音和已完成的二次稿；点击**继续二次识别**只处理余下片段。主动停止的任务重开应用后仍保持停止。
6. 更新术语、背景或语言后，点击**重新二次识别**，从头使用当前设置重新处理。继续／重试仍沿用上次设置和进度。此前版本保留在**逐字稿版本**中；新一轮完成前仍显示上一次完整结果。
7. 复制或导出前，选择所需的逐字稿版本和语气词显示设置。显示过滤不会改写模型原始文字。

默认快捷键为 Control + Option + R（开始）、S（停止）、L（显示主窗口），三个操作都需要前面两个修饰键。可在“设置 → 快捷键”修改。隐藏 Dock 的选项仅对快捷键启动的录音生效，菜单栏入口保留。

## 常见问题

| 现象 | 检查办法 |
|---|---|
| 麦克风音量一直为零 | 输入设备、物理静音、是否合盖及麦克风权限；打开屏幕或使用外接麦克风后重新自检 |
| 电脑声音一直为零 | 播放声音，检查屏幕与系统音频权限，再运行自检；部分受保护内容可能无法采集 |
| 升级试用版后显示允许却仍报拒绝 | 退出应用，在系统隐私设置中移除旧的系统音频条目，重新添加 Applications 中的当前应用。自行完成系统验证后重开，避免重置其他应用权限 |
| 模型下载失败 | 检查 Hugging Face 网络连接、磁盘空间和模型目录；重试可以续传，不要把未完成文件手动改名为正式模型 |
| 模型或转写停止 | 查看错误，可能触发了内存保护；录音保留。释放内存后继续或重试待转写任务 |
| 外接存储不见了 | 接回原磁盘，或在设置中明确选择、迁移目录；应用不会静默改存到其他录音位置 |
| 同一句话出现两份 | 使用耳机；目前没有声学回声消除 |
| 专业术语识别错误 | 会前加入简洁的术语与背景；二次识别可利用更完整上下文，但仍需校对 |

## 升级、备份与卸载

v0.4.4 将应用从 LocalScribe 更名为 **LocalVerbatim**，中文名为**本地逐字稿**，应用文件为 `LocalVerbatim.app`。为保持升级兼容，应用标识仍为 `local.localscribe.meeting-recorder`，默认数据根目录仍为 `~/Library/Application Support/LocalScribe/`。已有自定义存储路径、会议 ID 和音频路径保持不变，请勿为了匹配新名称而重命名数据目录。用户缓存或自定义目录中的模型会直接复用。

部分早期私人试用版将模型放在应用包内部。若用不带权重的 DMG 替换，请保留旧应用，通过向导导入旧应用内的 `Contents/Resources/Support/models/Qwen3-ASR-1.7B-bf16` 文件夹；这会校验并复制现有模型，无需重新下载。本地制作的升级包也可直接保留原有内置权重。

手动升级时，先退出旧应用、安装 LocalVerbatim，并在确认新版能打开原会议之前，将旧应用保留为 Applications 以外的备份，不要同时运行新旧版本。应用内名称跟随界面语言；Finder 和系统弹窗名称由 macOS 选择的本地化决定。

升级前停止录音并退出，再替换 Applications 中的应用。独立安装版把用户数据放在应用之外，替换应用包会保留数据。重要升级前，备份当前录音目录、`settings.json` 和 `preferences.json`，也要包含自定义存储位置；模型可以重新下载。

默认数据根目录为 `~/Library/Application Support/LocalScribe/`，包含 Recordings、Models、设置、术语偏好、诊断及日志。录音和模型可以使用自定义路径。开发版则使用源码目录，详见[开发说明](DEVELOPMENT.zh-CN.md)。

在应用中删除会议，会把完整会议文件夹连同两条录音移入系统废纸篓。清空废纸篓前，可退出应用，将整个会议文件夹（包含隐藏文件）移回当前 Recordings 目录来恢复。另行导出的副本不受影响。

卸载时，如已开启“登录时启动”，先关闭该项，退出应用后把应用移到废纸篓。会议和模型缓存仍保留。若也要删除用户数据，请先备份，再检查并删除实际使用的数据目录，不要假设所有文件都在默认路径中。

## 0.4.5 起的会议目录

首次启动会把旧 UUID 目录整理为类似 `2026-11-16 10-00 · 每周例会 [12345678]/` 的名字。顶层是完整的 `microphone.wav` 和 `system.wav`；`Transcripts/` 中保存 `original`（原稿）和 `refined`（二次稿）的 TXT、Markdown、SRT。隐藏目录 `.localverbatim/` 保存元数据、笔记、录音片段、原始识别输出和二次识别进度。隐藏只是整理方式，不是加密；Finder 中按 Command–Shift–句号可显示。

修改会议标题后，会等录音和识别空闲再更改目录名。会议 ID 和音频内容保持不变。升级前请备份完整录音库，包含隐藏文件。遇到同名目标时整理会停止，不覆盖已有文件，请勿自行合并。旧版本无法读取此布局；如需降级，请在退出应用后恢复升级前的录音库备份。

0.4.6 新增二次识别历史版本；更早的应用版本不能保留这一字段。如需降级，请先恢复升级前备份。

## 二次稿减少口头重复

查看二次识别结果（包括历史版本）时，勾选“减少语气词与重复”会合并明显的重复起头，例如“我我我先解释这个这个方案”显示为“我先解释这个方案”。旧会议也立即生效，无需重跑模型。取消勾选可查看原始文字；复制和手动导出跟随当前显示，自动保存的原文、录音和时间戳保持不变。这是保守的中文阅读整理，不是摘要或语法改写；正常叠词、技术内容和否定表达应保留，不能保证处理所有口头停顿。
